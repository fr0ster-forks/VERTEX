# Choose the assistant

The VERTEX panel's chat answers with one of:

- **Claude Code** or **Codex** - your subscription, through the CLI installed on this computer
- **GitHub Copilot** - a model made available by the signed-in Copilot extension through VS Code
- **Anthropic, OpenAI, Mistral, Gemini, Groq, Cerebras, OpenRouter or NVIDIA API** - with a provider-specific key kept in VS Code's secret storage

Pick the provider and model at the bottom of the panel. **LLM Providers** at the top lets you expand each provider's model list, enable models, and add named API keys. Select the active key manually; existing single keys appear as `DEFAULT`.
